# Student Services Portal



A professional TypeScript foundation for the University Student Services Portal featuring strong typing, generic API response wrappers, runtime validation guards, ESLint linting, and Prettier code formatting.



## Requirements

- **Node.js**: v20+ or v24+

- **Package Manager**: npm

- **Version Control**: Git



## Installation Instructions

Clone the repository and install dependencies:



```bash

git clone https://github.com/<YOUR-USERNAME>/student-services-portal.git

cd student-services-portal

npm install --legacy-peer-deps

```



## How to Run the Project

Execute the main application file using `tsx`:



```bash

npm run start

```



## How to Run Linting

Check for code style issues and static type errors:



```bash

npm run lint

```



## How to Format Code

Automatically format source files according to Prettier rules:



```bash

npm run format

```



## Development Workflow

1. Create a feature branch for new tasks (`git switch -c feature/<feature-name>`).

2. Implement and test changes locally.

3. Ensure linting (`npm run lint`) and formatting (`npm run format`) scripts pass cleanly.

4. Push the feature branch to GitHub and open a Pull Request against `main`.

5. Perform code review and merge upon approval.

AI tools may be used to assist development. All AI-generated code must be reviewed, modified when necessary, tested, and verified before commit.
